# Git Grapher

A visual Git playground for learning, teaching, and explaining Git workflows.

## Demo

[Live Demo](https://git-grapher.netlify.app/)

## What is Git Grapher?

Git Grapher lets you create branches, commits, merge requests, and tags visually, then export clean Git workflow diagrams for learning, teaching, and documentation.

## Use Cases

- Learn Git visually
- Teach Git concepts
- Explain team workflows
- Create Git workflow diagrams for documentation

## Features

- Create branches
- Create commits
- Create merge requests
- Merge merge requests
- Create tags
- Import/export graph JSON
- Export graph as PNG
- Use ready-made workflow templates
- Try Pro placeholders for export and premium-template validation
- Send feedback or join the Pro waitlist through Netlify Forms
