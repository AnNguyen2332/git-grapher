# Git Grapher

Git Grapher is a visual Git graph simulator that turns user actions such as creating branches, commits, merge requests, merges, and tags into a clean, intuitive, and beautiful Git graph.

This tool was created primarily to solve a personal need, so it may not be perfect yet. Please do not hesitate to share feedback with me if you run into any issue or have ideas for improvement.

## What It Does

- Create branches from a chosen branch.
- Add commits and visualize them on a horizontal Git graph.
- Create and merge simulated merge requests.
- Add tags near selected commits.
- Delete branches or remove a commit and its dependent commits.
- Switch the root branch label between `main` and `master`.
- Export the graph as a PNG image.
- Persist simulator state locally in the browser.
